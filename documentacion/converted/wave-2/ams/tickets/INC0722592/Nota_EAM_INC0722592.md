# Upload file XML applicazione

Accedere ad IBM MAS Manage in lingua inglese utilizzando un’utenza amministrativa tramite il link riportato di seguito: https://masbus.manage.mas.servizi.prv/maximo

Dopo aver eseguito l’accesso, accedere all’applicazione Application Designer. Una volta all’interno dell’applicazione, selezionare l’azione Import Application Definition situata nella colonna sinistra sotto il menù Common Actions.

Verrà aperta una dialog in cui poter caricare il file XML dell’applicazione. Una volta caricato cliccare OK.

La procedura di upload dell’applicazione è terminata.
