# Generazione pagina di richiesta report

Accedere ad IBM MAS Manage con un’utenza amministrativa utilizzando il seguente link https://masbus.manage.mas.servizi.prv/maximo

Una volta eseguito l’accesso, ricercare l’applicazione Report Administration utilizzando la barra di ricerca.

All’interno dell’applicazione, cliccare sull’azione Generate Request Pages e attendere il completamento dell’operazione.
